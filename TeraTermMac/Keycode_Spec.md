# Keycode.app 仕様書

macOS 版 TeraTerm（TeraTermMac.app）の KEYCODE.EXE 移植アプリ。

## 概要

Windows 版 TeraTerm に付属する KEYCODE.EXE を macOS ネイティブアプリとして移植する。
キー入力に対応する PC key code を表示し、KEYBOARD.CNF の設定に使用できるようにする。

## PC key code 算出仕様

### 基底値

macOS の `NSEvent.keyCode`（UInt16、0〜127）をそのまま基底値として使用する。

### 修飾キーの組み合わせと加算値

| 組み合わせ               | 加算値 | 説明                                         |
|--------------------------|--------|----------------------------------------------|
| 単独キー                 | 0      | 修飾キーなし                                 |
| Shift+key                | +256   | Shift のみ                                   |
| Ctrl+key                 | +512   | Control のみ                                 |
| Shift+Ctrl+key           | +768   | Shift + Control（256+512）                   |
| Shift+Option+key         | +1280  | Shift + Option（256+1024）                   |
| Ctrl+Option+key          | +1536  | Control + Option（512+1024）                 |
| Shift+Ctrl+Option+key    | +1792  | Shift + Control + Option（256+512+1024）     |
| Option+key（Meta）       | +2048  | 手動計算・UI で案内のみ（直接表示しない）    |

### 修飾キーのビット構成

| ビット | 値   | 修飾キー |
|--------|------|----------|
| bit 8  | 256  | Shift    |
| bit 9  | 512  | Control  |
| bit 10 | 1024 | Option   |

Option 単独の場合は +2048 として手動計算を UI で案内する。

## UI 仕様

### ウィンドウ

- サイズ：固定 480×320pt（リサイズ不可）
- タイトル：「Keycode」

### 表示レイアウト

```
┌─────────────────────────────┐
│        Push any key.        │  ← 案内テキスト（上部・中央）
│                             │
│    Key code is XXXX.        │  ← キーコード表示（中央・32pt）
│                             │
│      Shift + Ctrl + A       │  ← キー文字列表現（中央・13pt）
│                             │
│ Option+keyのコードは         │  ← Option案内（下部・11pt・グレー）
│ 単独コード+2048で計算して    │
│ ください                    │
└─────────────────────────────┘
```

### 動作

- 起動時：「Push any key.」表示、キーコードラベルは「---」
- キー押下時：PC key code を計算し表示を更新
- 修飾キー単独（Shift/Ctrl/Option/Command）は無視
- 次のキー押下で表示を上書き更新

### 多言語化

## KEYBOARD.CNF 出力仕様

- 改行コード：LF（macOS 標準）
- 文字コード：UTF-8（macOS 標準）
